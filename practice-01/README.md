Задание 2:

1. "8" + 2
Ожидание: ошибка.
Фактически: "82", тип - string.
Почему: оператор + перегружен. Если хотя бы один операнд является строкой, второй тоже неявно приводится к строке, и выполняется конкатенация.

2. "8" - 2
Ожидание: ошибка.
Фактически: 6, тип - number.
Почему: оператор - не умеет работать со строками. JavaScript автоматически приводит операнды к числам: "8" в 8

3. Number("8") + 2
Ожидание: 10 (число).
Фактически: 10, тип - number.
Почему: функция Number() явно преобразует строку в число 8. После этого оба операнда — числа, и + работает как обычное арифметическое сложение

4. "12" > "3"
Ожидание: true
Фактически: false, тип - boolean.
Почему: оба операнда - строки, поэтому сравнение идёт лексикографически (посимвольно, по кодам символов). "1" (код 49) меньше "3" (код 51), значит результат false

5. 12 === "12"
Ожидание: false
Фактически: false, тип - boolean.
Почему: оператор === - строгое сравнение, проверяет и значение, и тип, без приведения типов. Слева number, справа string - разные типы, поэтому false

6. Number("")
Ожидание: NaN 
Фактически: 0, тип - number.
Почему: пустая строка при преобразовании к числу даёт именно 0. Строка только из пробелов (Number("   ")) тоже даёт 0, потому что пробелы обрезаются.

7. Number("text")
Ожидание: NaN
Фактически: NaN, тип — number.
Почему: строку "text" невозможно интерпретировать как число, поэтому Number() возвращает специальное значение NaN (Not a Number). Ошибка при этом не выбрасывается. Тип у NaN - именно number, потому что это особое числовое значение.

8. Boolean("false")
Ожидание: true
Фактически: true, тип — boolean.
Почему: Любая непустая строка — истинная 

9. typeof null
Ожидание: "null".
Фактически: "object", тип — string.
Почему: null это нулевой указатель, это совпаадет с тегом объекта 

10. typeof NaN
Ожидание: "number".
Фактически: "number", тип - string.
Почему: NaN - числовое значение. typeof возвращает тип в виде строки

Задача 8. Доп.
Проверка на отрицательность пропускает всё, кроме отрицательных чисел: NaN сравнивается как false, пустой ввод и null дают 0, а Infinity и дробные вообще не отрицательны. Поэтому не следует использовать только проверку на отрицательность.
